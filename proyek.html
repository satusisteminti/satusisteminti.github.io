Layanan inti yang kami bangun.

Fokus kami menyelesaikan masalah pelanggan. Untuk itu kami juga membangun layanan inti sendiri dengan API berbasis Go: pengguna, penagihan, persetujuan, notifikasi, dan jejak audit. Layanan ini dipakai ulang, sehingga waktu kami tercurah untuk masalah Anda.

Daftar proyek

Layanan inti, satu fondasi

Modul di halaman Solusi memakai layanan-layanan ini. Karena dibangun sekali dan dipakai bersama, setiap modul langsung mendapat akun, hak akses, notifikasi, dan jejak audit yang sama.

Lihat modul di halaman Solusi

  1. P01

    User Management

    Manajemen pengguna & akses

    Satu akun untuk semua modul. Mengatur pengguna, unit organisasi, peran, dan izin akses dari satu tempat.

    Dalam pengembangan

    Fitur

    • Single sign-on (SSO)
    • Peran & izin per modul (RBAC)
    • Multi unit organisasi
    • Autentikasi dua faktor
    • Riwayat login

    Teknologi

    • Go
    • PostgreSQL
    • Redis
    • OAuth 2.0 / OIDC

  2. P02

    Billing

    Penagihan & pembayaran

    Pembuatan tagihan, langganan berulang, dan pencatatan pembayaran yang langsung tersambung ke modul keuangan.

    Dalam pengembangan

    Fitur

    • Tagihan sekali & berulang
    • Integrasi payment gateway (VA, QRIS)
    • Pengingat jatuh tempo
    • Rekonsiliasi pembayaran
    • Faktur PDF

    Teknologi

    • Go
    • PostgreSQL
    • Webhook

  3. P03

    API Gateway

    Pintu masuk API terpusat

    Satu pintu untuk semua permintaan ke layanan inti: memeriksa token, membatasi laju permintaan, dan mengatur versi API.

    Dalam pengembangan

    Fitur

    • Validasi token akses
    • Pembatasan laju (rate limit)
    • Versi API
    • Dokumentasi OpenAPI

    Teknologi

    • Go
    • Redis
    • OpenAPI

  4. P04

    Workflow

    Alur kerja & persetujuan

    Mesin alur persetujuan yang bisa diatur tanpa mengubah kode, dipakai oleh pengajuan anggaran, cuti, surat, hingga permintaan barang.

    Dalam pengembangan

    Fitur

    • Persetujuan bertingkat
    • Delegasi wewenang
    • Batas waktu & eskalasi
    • Riwayat keputusan

    Teknologi

    • Go
    • PostgreSQL

  5. P05

    Notification

    Notifikasi multi-kanal

    Mengirim pemberitahuan dari semua modul lewat satu layanan, dengan templat dan antrean pengiriman.

    Dalam pengembangan

    Fitur

    • Email
    • WhatsApp
    • Notifikasi aplikasi (push)
    • Templat pesan
    • Antrean & kirim ulang

    Teknologi

    • Go
    • Redis

  6. P06

    Audit Log

    Jejak audit terpusat

    Mencatat setiap perubahan data dari semua modul: siapa, kapan, apa yang berubah, beserta nilai sebelum dan sesudahnya.

    Dalam pengembangan

    Fitur

    • Pencatatan otomatis
    • Pencarian & filter
    • Ekspor laporan audit

    Teknologi

    • Go
    • PostgreSQL

  7. P07

    Document Storage

    Penyimpanan dokumen

    Penyimpanan berkas bersama untuk semua modul, dengan hak akses per dokumen dan riwayat versi.

    Dalam pengembangan

    Fitur

    • Hak akses per berkas
    • Riwayat versi
    • Pratinjau dokumen
    • Pencarian

    Teknologi

    • Go
    • Object storage (S3)

  8. P08

    Reporting

    Laporan & dasbor

    Menyusun laporan lintas modul langsung dari inti data, untuk dasbor pimpinan maupun laporan berkala.

    Dalam pengembangan

    Fitur

    • Dasbor pimpinan
    • Laporan terjadwal
    • Ekspor Excel & PDF

    Teknologi

    • Go
    • PostgreSQL

Cara kami membangun

Prinsip di setiap proyek.

Layanan terpisah, satu inti data
Setiap proyek berjalan sebagai layanan sendiri sehingga mudah dirawat, tetapi semuanya memakai inti data dan akun pengguna yang sama.
API berbasis Go
Seluruh layanan inti dibangun dengan Go: ringan, cepat, dan stabil untuk beban kerja banyak pengguna sekaligus.
Terdokumentasi
Setiap API dilengkapi dokumentasi OpenAPI, sehingga modul baru atau sistem lain dapat terhubung tanpa menebak.
Dipakai ulang di setiap implementasi
Layanan yang sama dipasang di setiap organisasi klien, sehingga implementasi berikutnya lebih singkat dan perbaikan dirasakan semua klien.
